Goal of this project is to build a Python-based computational tool that automates the
stress analysis of circular shafts subjected to two twisting loads each at a Fixed-Fixed and a Fixed-Free
(Cantilever) support. To thoroughly investigate the torsional behaviour of both solid and hollow shafts,
our program is designed to:
• Calculate and plot the internal torque (how it varies along the shaft depending on the supports
(fixed-free vs fixed-fixed)), maximum shear stress (τmax) (how that shear stress distributes across
the cross section (solid vs hollow circular beam)).
• For any specific cross-section and form of support, plot Mohr’s circle to find the principal stresses
and use it to calculate stress on a rotated element. This provides a clear, visual breakdown of how
stresses transform, highlighting the maximum shear and principal normal stresses.
